# 🔐 Week 3 – Password Cracking

### Cybersecurity & Ethical Hacking | Networkwalks

This repository documents my hands-on practical activities completed during Week 3 of the Networkwalks Cybersecurity & Ethical Hacking Program.

## 📌 Project Overview

The objective of this lab was to understand PDF password protection, hash extraction, and password recovery techniques using authorized cybersecurity tools.

## 🎯 Learning Objectives

- Understand password hashing and PDF encryption.
- Learn how to extract password hashes from protected PDF files.
- Practice using John the Ripper and Johnny GUI.
- Explore password recovery using Networkwalks tools.
- Understand the importance of strong passwords.

## 🧪 Completed Practical Modules

### ✅ W3-PM1: Password Cracking with JTR

**Tools Used:**
- John the Ripper (JTR)
- Johnny GUI
- PDF Hash Extractor
- Windows 11

**Activities:**
1. Downloaded and configured John the Ripper.
2. Installed and configured Johnny GUI.
3. Extracted the hash from the assigned PDF file.
4. Saved the hash in a text file.
5. Loaded the hash into Johnny.
6. Performed the password recovery process.
7. Verified the recovered password by opening the PDF.

### ✅ W3-PM2: Password Cracking with Networkwalks Tools

**Tools Used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser

**Activities:**
1. Uploaded the assigned PDF to the Hash Calculator.
2. Extracted the PDF hash.
3. Submitted the hash to the Password Cracker.
4. Performed the password recovery process.
5. Verified the result by opening the PDF.

## 🧠 Key Learnings

- PDF password protection and hash extraction.
- Practical experience with password recovery tools.
- Basic understanding of password security.
- The importance of strong and unique passwords.
- Hands-on experience with ethical hacking techniques.
